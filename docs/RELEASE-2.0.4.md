# AI 酱 2.0.4

本体新增「一起玩牌」所需的牌桌服务和本地钱包支持。插件 1.0.0 独立提供，从扩展中心的官方目录安装。支持斗地主和德州扑克，包含发牌与公共牌动画、斗地主结束后亮出剩余手牌、牌桌暂停和续玩。合成模型测试可验证流程，真实模型的牌力和响应质量尚未验收。

- 30fps 和 60fps 使用同一套功能，复用 2.0.3 的动画素材。
- B站陪伴 2.0.11 和 QQ连接 2.0.6 保持原版本。
- 本体和插件源码公开，项目代码采用 Apache-2.0 + Commons Clause。素材与第三方组件的条款见各自的第三方说明。

## 升级与回退

首次打开旧存档时，钱包由 schema 1 升到 schema 2。升级前请备份原存档。2.0.3 不支持写入 schema 2，切回旧程序入口无法撤销迁移。安装器在新程序可能已经迁移钱包时保留资料和两个版本的程序，可用 2.0.4 安装器修复。确需使用 2.0.3 时，另行打开升级前备份的副本，并保留已经升级的存档。
