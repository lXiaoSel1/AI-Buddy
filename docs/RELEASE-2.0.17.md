# AI 酱 2.0.17

本次本体更新包含 2.0.15 以来的语音、QQ 连接和存档保护修复。已安装的语音和 QQ 插件可以继续使用。

## 语音

- 修复 Windows 上 GPT-SoVITS 组件校验通过后，因启动路径而报 `ModuleNotFoundError` 的问题。Breeze 保持原有启动方式。
- 停止朗读只跳过当前回复的配音。结束 Live、取消录音或麦克风访问失败后，已就绪的语音引擎仍可读下一条回复。在语音识别加载中取消 Live，也会保留已就绪的配音引擎。
- Live 开始新一轮收音时清除上一轮的识别文字。麦克风启动时显示「准备中」，录音完成后显示「识别中」。
- 批量准备只检查已安装的语音引擎，按实际需要克隆的音色显示数量和预计费用。云克隆要求至少 10 秒的参考录音，短录音在估价和上传确认前拦截，仍可用于本地配音。

## QQ 连接

- 修复临时扫码进程退出后仍提示「上一次连接仍在关闭」的问题。退出或重试扫码时会继续核对清理，在停止回执的文件占用解除后可以恢复。
- 在准备扫码组件时取消，会等本次占用释放后再显示取消完成，可以随即重新扫码。

## 存档保护

- 启动和导入时先核对陪伴快照。最新快照缺失或校验失败时，可读取仍可校验的较早快照。已有快照记录无法读取时，保留原文件和历史。
- 社交账号库无法读取时，Galgame 和扩展中心仍可启动。需要该库的 QQ、B站账号操作会暂停，界面会显示诊断信息，重启时重新检查。

可在「通用设置 → 本地安装」检查更新，也可运行 2.0.17 安装器并选择原安装目录。
