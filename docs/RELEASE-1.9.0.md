# AI 酱 1.9.0

本版整合已验收的 59 个界面改版、多人分区舞台、角色独立聊天连接与 effort、桌宠互动，以及长期记忆、人格成长和完整人生存档。30fps 与 60fps 功能及存档格式相同。

## 主要变化

- 群聊有自己的标题、背景、成员、记录、模型配置及 CG 图鉴。最多四人同屏，发言者高亮，人数增加时切换区域；复用普通立绘和八表情。自然模式按点名和角色健谈程度选人，第一位自动回复，后续仍点击继续。
- 每位角色默认跟随全局聊天连接，也可使用独立 API 或本机 Codex 配置及其模型、effort。群聊合影可单独选择提示词策划连接，绘图连接独立。
- 角色卡、Persona、会话历史及更正保留各自归属。完整原文实时保存，日终 Summary/Guide 使用分段预算和来源校验；普通记忆不自动淡忘。人格成长需明确开启，完整人生支持成套归档、导出、导入、重置及恢复。
- 左拖走动、右拖甩飞；右拖中按住左键蓄力，松左键发射。新增睡眠、唤醒和飞行动作，局部白手套有食指轻戳。点击好感每角色 60 秒最多一次、每日最多 30 点。
- 工作状态条可关闭并撤销；状态条、反馈气泡、群聊工具栏和主题统一。任务栏/托盘图标以实际正在显示的桌宠为准。
- 审计修复包括历史快照保留、工作 Token 旁路写入、人生事务恢复与安全模式、回复截断重试、图片引用保存、图库按悬停解码及视线资源释放。

## 资源与下载

11 位角色各 24 段独立透明动作（原 18 段加 6 段睡眠/飞行互动），每档 264 段。已批准视频采用 CRF 28；保留动作时间轴、画布、尺寸、锚点及透明度，新互动静帧为 WebP Q95，视线方向图不重复压缩。

| 下载/安装内容 | 30fps | 60fps |
|---|---:|---:|
| 全角色在线资源下载，约 | 1.66 GiB | 2.33 GiB |
| 完整便携 ZIP，约 | 1.70 GiB | 2.37 GiB |
| 离线分卷数 | 2 | 3 |
| 完整安装含维护器，约 | 1.96 GiB | 2.62 GiB |

在线 ZIP 均可独立解压，每包不超过 1 GiB；完整离线 ZIP 使用至多 1 GiB 的分卷，需用附带工具全部合并后解压。精确长度、SHA-256 和最终实测结果见对应 Release 的校验与验证附件。

## 安装、升级与回退

下载 [AI-Buddy-Setup-1.9.0-win-x64.exe](https://github.com/lXiaoSel1/AI-Buddy/releases/download/v1.9.0/AI-Buddy-Setup-1.9.0-win-x64.exe)，选择位置、帧率及角色。旧 1.8.0 EXE 固定旧清单；升级请下载此新版安装器并选择原目录，新版会接管路径并保留个人数据、有效设置及自定义数据目录。无需另装 .NET、Node.js 或 Python。

同版本维护器支持角色补装、修复、切换帧率和同格式程序回退。升级前等待目标实例聊天/CG 完成并正常退出；回退不把旧备份覆盖到新存档。返回 R2 之前版本时需检查图片/草稿及人生数据兼容性，存在不兼容数据则拒绝自动降级。数据维护 T1/T2/T3 单独安排，每次执行均先确认当前 planId；本次媒体/程序更新不夹带维护。
