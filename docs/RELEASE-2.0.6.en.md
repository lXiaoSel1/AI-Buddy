# AI Buddy 2.0.6

This release brings the 2.0.5-r2 installer fix to the stable update channel. Older installers can find 2.0.6 through Check for updates. The installer stays responsive while verifying legacy profile snapshots and still rejects mismatched hashes.

To upgrade, select the existing installation folder and leave the offline resource folder blank. Application features, characters, animations and Electron runtime carry over from 2.0.5. Published plugins remain compatible.
