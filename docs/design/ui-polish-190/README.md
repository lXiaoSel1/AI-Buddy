# AI 酱 1.9.0 UI 改版：设计源文件

设计稿网页：https://claude.ai/artifact/VNnLBZuNRWH1fLWfouw4nt（59 个界面全部已批准）。

这个目录保存设计稿的源文件，方便以后改主题或重新生成素材。打包后的整页 HTML 不进仓库，备份在 `local/design-archive/`。

## 目录

| 路径 | 内容 |
|---|---|
| `ai-theme/index.html` | 11 套主题的色板（`THEMES`）、背景定位（`GEN_POS`）、额外效果（`EXTRA`） |
| `ai-theme/build.py`、`check_contrast.cjs` | 主题页的打包脚本和对比度检查 |
| `ai-theme/gen/brief.md`、`gen/web/*.webp` | 背景图和立绘小装饰的生图说明与成品 |
| `ui-design/src.html`、`sec1/3/4/5.{js,css}` | 59 个界面的设计稿；`HEAD_SYS` 和 `ACC_SIZE` 也在 `src.html` 里 |
| `ui-design/faces.py` | 每个角色的眼睛坐标，头像按它居中裁剪 |
| `ui-design/build.mjs`、`snap.mjs`、`extra/*` | 设计稿的打包和截图脚本 |
| `tools/make_theme_assets.py` | 生成 `assets/theme/<id>/`：bg、orn、head、icon-256、tray-16/24/32 |
| `tools/tokenize-colors.mjs`、`retire-aliases.mjs` | B0 把写死的颜色换成 `--buddy-*` 变量时用过的脚本 |
| `color-map.md` | 旧颜色到新变量的对照表 |

色板由 `scripts/extract-theme-palettes.mjs` 从这里抽出，生成 `src/theme-palettes.mjs` 和 `src/appearance.css` 里的 `@generated theme-tokens` 段。改了设计源文件以后重新运行它；`--check` 检查两者是否同步，测试里也会跑。
