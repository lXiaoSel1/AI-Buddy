# 1.9.0 角色、群聊与桌宠互动

当前功能已由用户验收，纳入正式代码版本 1.9.0。双帧率本机版本均保留 11 位各 24 项、共 264 项动作，复用已批准的立绘、八表情与透明素材。原入口已经完成本机实装；本次只提交源码，尚未发布 1.9.0 安装器或 Release。

## 使用入口

Galgame 工具栏的“管理角色”可以创建、保存草稿、编辑和选用角色。“我的身份”管理多份 Persona。“对话历史”管理完整会话。“群聊”承接持续多人对话与合影；原有小剧场在“历史剧场”中保留回看，不再提供重复的新建入口。返回私聊恢复进入前的角色、身份、会话、草稿和手动／跟随模式。

角色卡支持逐字段继承、自定义和主动清空。只有名称必填。自建角色没有立绘时仍可文字聊天，没有桌宠资源时保留当前可用桌宠。保存角色不会请求模型或自动创建素材。每位角色默认沿用全局聊天连接，也可在角色设置中选择已有的专属连接；私聊与群聊使用相同规则。专属连接失效会提示原因，不静默换用另一条；角色形象不随实际 API 改变，绘图仍使用独立 CG 连接。

Persona 与会话、草稿和回复选项绑定。不同身份的聊天不自动共享；每个角色默认分别计算关系进度。首次改为共用时选择一份已有进度，不相加。以后切回独立模式会恢复原记录。新建会话沿用当前身份，尚未选择时才使用默认身份；不会重写已有会话的绑定。CG 图鉴仍按角色保存，并记录身份来源。

完整原文保存在本地；模型上下文按角色、Persona、群聊知情范围、核心/Guide 及有关原文构建；容量不足时分段压缩，不以固定消息条数静默删除原文。用户消息更正默认关闭，开启后保留原文和版本，不自动重答，也不重新奖励。AI 消息不能直接修改。历史支持继续、新建、改名、查找、收藏、归档、导出恢复，不提供永久删除。

群聊默认自然模式，按绑定 ID 的 @、健谈程度（默认 50%）选择本轮名单，没有固定三人上限；每人本轮最多一条。每条呈现后点击“继续”才执行下一位。停止、离开当前群或切换身份会取消未呈现的回复及剩余队列，已呈现的内容保留。新加入或缺席的成员不会获得相应时间段的消息；私聊不会自动进入群聊。跟随桌宠保持进入群聊时的角色，固定模式继续有效。群导出包含成员参与区间；可在历史恢复入口导入。选装版在进入群聊或新一轮请求前检查全部内置成员素材，缺包时先提示补装，取消不会改变当前群或发起模型请求；自建文字角色不要求素材包。

群聊采用站姿分区舞台，复用普通立绘与八表情，不为每句话重新画图。宽度至少 900 DIP 时同屏最多四位，660～899 DIP 为三位，更窄为两位；群成员总数不受同屏容量限制。当前发言者高亮，其他同屏角色降低亮度。手动浏览不会改变实际发言者、台词、成员知情范围或桌宠；“回到发言者”恢复镜头，“全员总览”搜索和定位成员。打开总览不开始下一条请求，已经在执行的结果暂存到关闭后呈现。

“合影 CG”依据本次已呈现的群聊内容和实际参与者生成，镜头外的参与者也包含在选择范围内。每个群可选“结束本次聊天时自动合影”，默认关闭；返回私聊或关闭窗口不会自动生成。参考图容量不足会明确提示，主题成功后重试复用，相关图鉴引用同一个图片文件。合影不重复结算聊天好感。

通用设置提供自动睡眠、物理互动和四档力度。左键单击桌宠有效轮廓播放八表情动作，避免连续重复；右键单击打开“打开工作空间”菜单。点击奖励记给实际桌宠及当前 Persona，每角色滚动 60 秒最多 +1、系统本地日期每天最多 30，同角色不同身份共用额度。表情不受奖励冷却限制。拖动、右键、飞行抓取及取消不奖励。

自动睡眠为五分钟无有效活动；索引、历史补录、额度和价格刷新不算活动，外部 running 也不能无限保活。真实内置聊天与绘图生命周期保持清醒，失败或取消后释放。新 Token、点击和任务反馈会唤醒，唤醒后有五分钟保护。重新启动从五分钟重新计时。

左键拖动显示左右走动，松手停放；右键拖动后快甩进入重力飞行，慢放或停顿后释放则原地放置。右键拖动中按住左键进入弹弓蓄力，松左键反向发射一次；先松右键不会发射，仍等左键释放。Esc 取消手势，空中抓取立即清零速度并跟手。发射后剩余按键释放不会触发菜单、奖励或第二次发射。

动作展示按选中角色显示原 18 项与新六项：入睡过渡、睡眠、唤醒、起飞、飞行、落稳恢复。只播放可见卡片，支持统一暂停及在桌宠临时演示。所有 11 位角色均有自己的 24 项资源，不借用另一角色的动画。本次已批准素材的技术验收与用户观感结论均保留记录，不重新生成媒体。
