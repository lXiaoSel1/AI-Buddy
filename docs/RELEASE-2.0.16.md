# AI 酱 2.0.16

这次本体补丁修复了 Galgame 语音、MiniMax 云音色准备和 QQ 重新扫码。

- 批量准备按已安装的语音引擎检查声音档案。有至少一份档案的角色可以选，确认窗口按实际需要克隆的音色显示数量和预计费用。
- 云端克隆要求参考录音至少 10 秒。短录音会在估价和上传确认前被拦截，上传前会再次校验实际时长。短录音仍可用于本地配音。
- 停止朗读只跳过当前回复的配音，文字继续生成。结束 Live、取消录音或麦克风访问失败后，已就绪的配音引擎可以继续读下一条回复。加载语音识别时取消 Live 也会保留此前已就绪的配音引擎。
- Live 开始新一轮收音时会清除上一轮字幕。
- 麦克风启动时显示「准备中」，说完后才显示「识别中」。
- QQ 重新扫码会先清理上一次连接尝试。清理完成后可获取新二维码，取消时会释放本次尝试。

可在「通用设置 → 本地安装」检查更新，也可运行 2.0.16 安装器并选择原安装目录。现有语音插件 1.0.3 可以继续使用。
