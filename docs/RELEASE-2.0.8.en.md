# AI Buddy 2.0.8

Settings now connects version checks, downloads, preparation and installation to the background update helper. Keep using the current version while an update is prepared, then choose Later or Install and restart. Installation waits for active work to finish safely. Normal updates do not require a browser or installation wizard.

The distribution includes a matching app, helper and manifest. The installation transaction verifies actual files before registering update capability. Trusted migration of older installations is separate from recovery of damaged installations. Older clients without migration capability need one guided installation; subsequent updates can run inside the app.

Plugin updates retain the extension center's signed sources, permission checks and maintenance queue. Updates are manual by default, with eligible automatic patch updates available per plugin. Enabled state and plugin data are retained. Additional permissions still require confirmation.

Previously accepted fixes for group presentation acknowledgements, streaming display, online-chat preferences and the character list in small windows are retained. Updates preserve profile location, wallet, character resources and animation profile, and reuse components with matching hashes.

Verification records distinguish code, isolated installation, installation on the target machine and publication. Synthetic models and test signatures do not establish real-model or official-release acceptance. Fullscreen disappearance and global pointer stalls still require field evidence.
