# 语音插件接口兼容约定

语音包版本的大版本就是接口版本。AI 酱从 2.0.14 起声明支持接口 `[1]`：符合现有清单要求的稳定 `1.x.y` 引擎包和共享运行包使用同一规则，不接受预发布或构建元数据后缀。每个引擎依赖的 `ai-buddy.voice-shared-runtime` 版本必须精确等于引擎自身版本。来源签名、清单中的 `appRange` 及其他兼容检查仍然生效。

后续语音包的 `appRange` 只写下限，不写上限，例如 `>=2.0.14`。2.0.12 和 2.0.13 仍使用旧版本列表，不能识别 1.0.3 之后的版本，因此后续语音包的最低本体版本至少为 2.0.14。已发布包的签名清单保持原样。

本体修改语音相关代码时，对 `1.x` 语音包工作进程的启动参数、输入输出协议和资产清单格式只能增加可选项，不能改变已有项。需要不兼容改动时，应发布 `2.x` 语音包，并在本体的支持集合中加入 `2`，在一段时间内同时支持接口 `1` 和 `2`。
