# AI 酱 2.0.12

2.0.12 补齐语音档案选择和组件校验提示，整理扩展中心的官方语音登记及版本菜单。30fps 与60fps 两版功能相同；现有媒体、运行库和大模型组件继续复用。

## 她的声音

- 语音插件页「角色声音」列出当前浏览引擎下每位角色选中的声线。预制显示「预制声线」，自定义显示自己的标签；没有档案和读取失败分别提示。
- 当前角色有两份或更多档案时，在导入按钮左边显示「她的声音」下拉，可在预制和自定义录音间切换。预制排第一，自定义按导入时间排列，同名用日期区分；长名称单行省略，悬停可看全名。
- 切换正在朗读角色的声线会停止当前句，下一条回复使用新声音；声线及已有选择保留。Galgame 弹层仍只显示声线。语音三包保持1.0.2，不重新分发素材。

## 已装组件只需校验

- 插件升级后，组件描述没变但准备凭据需要重新绑定时，显示「需要校验」，由用户点「校验」，不会自动重新下载。
- 校验使用已有文件；失败后才提示重新下载。下载量为0时隐藏下载总量底栏。缺文件仍提示「还没准备好」。
- 非当前引擎也能查看和校验自己的组件，不会为此改掉当前配音引擎。普通状态查询不再逐个检查大组件的全部文件。

## 扩展登记和兼容性

- 只有匹配原官方签名、归档和提取文件的旧官方语音记录才迁入官方来源，保留启用状态、历史版本、原资料路径和角色声线。
- 官方语音在「已安装」显示一行；「更多」中可以切换版本、按成套计划回退或卸载并保留声音及设置。不能使用的历史版本显示原因，不删除已签历史。共享语音运行依赖跟随引擎，不单独堆卡。
- 扩展中心进入时刷新过期目录；本体不兼容但有兼容新版的插件会明确提示更新版本。
- B站陪伴2.0.15、QQ连接2.0.9、一起玩牌1.1.4只调整声明和文档：app/DSH只写下限，允许排序不早于下限的稳定或预览版；bridge/API继续保留接口上限和原预览版规则。业务逻辑、规则、权限和资料格式未改。声明允许安装不保证所有未来运行库都能运行，仍需每次发布前检查。

本批检查声线读取/选择、校验与下载分离、登记升级及版本切换、菜单、文案和实际Electron渲染。升级测试使用原签名包、隔离管理器及合成资料；没有重新验证真实模型音质、云服务、真实账号、10GB组件实际校验耗时或Windows鼠标手感。原聊天、声线和组件不因本批新增业务存档结构迁移。
