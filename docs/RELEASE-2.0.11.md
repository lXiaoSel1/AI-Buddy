# AI 酱 2.0.11

2.0.11 支持从正式语音插件自动补入 11 角色的预制声线。30fps 与 60fps 两版功能相同。

## 双引擎预制声线

- 预制参考随 Breeze、GPT-SoVITS 1.0.2 引擎包分发，共享运行组件同为 1.0.2；三包要求宿主 ^2.0.11。声线不放在宿主媒体资源或大模型组件包中。
- 首次安装或升级对应语音插件后，宿主从已验证的插件补入该引擎的 11 角色声线；两种引擎合计 22 档。重复安装和重启复用已有档案，不重复创建。
- 没有已有选择时可使用预制声线；已有选择、自定义声线及用户参考录音保持原样，不被覆盖。
- 参考来自已批准的 r04 素材，不重新生成或转码。GPT-SoVITS 保留短参考及全长云参考；全长参考仅作为本地资料保存。

## 变更与验证范围

导入不会自动上传参考、创建云端克隆音色或产生云配音费用。使用云服务仍需用户自行配置并明确授权相关操作。

本次不宣称重新验证真实模型推理、麦克风、云配音或实际音质与长期听感。既有媒体、运行库和大模型组件继续复用原有字节；用户资料格式不因预制声线导入而迁移。
