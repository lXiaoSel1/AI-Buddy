# AI Buddy 2.1.0

- Galgame private and group chats have updated scenes, character expressions, and dialogue controls. Chat history is paginated, and companion chat and activity storage move to SQLite.
- Built-in cloud voice adds separate recognition and per-character voice settings. Installed local voice engines remain available.
- Private chats using custom APIs can reuse session caches. Codex private chats retain their thread associations so you can continue them later.
- Companion storage, restore, and background saves block the desktop less. Offline meal assessment retries and plugin shutdown handling have been improved.
- Bilibili full reading checks segment subtitles and evidence, and can resume paid work with valid receipts after an official plugin update.

Check for updates in General Settings under Local Installation, or run the installer and select your existing installation directory.
