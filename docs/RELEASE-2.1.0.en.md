# AI Buddy 2.1.0

This app release includes the Galgame redesign, built-in cloud voice, session caching, companion storage improvements, and Bilibili full-reading fixes introduced in 2.0.18. See the [feature release notes](RELEASE-2.0.18.en.md).

Bilibili Companion uses its independent version 2.0.18 in Extensions. Check for the app update under General Settings → Local Installation, or run the 2.1.0 installer and select your existing installation directory.
