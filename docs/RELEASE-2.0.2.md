# AI Buddy 2.0.2

This release brings the accepted 2.0 companion interface and asynchronous activity/receipt fixes to the public distribution. Host version remains 2.0.2. Bilibili2.0.11 and QQ2.0.6 are independently versioned plugins; Work2.0.9 is not publicly distributed.

The extension center lazily loads the official signed community catalog. DSH component preparation uses a host-pinned download, checksum/inventory validation, bounded progress, cancellation and normal owned-worker shutdown. Bilibili plugin installation automatically prepares the fixed upstream FFmpeg component in that same flow. The public host does not mirror its executable/archive; verified existing copies are reused. No local audio transcription component is included. Existing approved all-C animation resources are reused without re-encoding; 30/60fps have the same application features.

Reading coverage, final reflection and unknown model results are separate states. Completed receipts stay local and ambiguous requests are not automatically replayed. Upgrade/rollback must retain existing chats, identities, connections, inventory, CGs, tasks and receipts; an unsupported old writer is refused.

See VALIDATION-2.0.2.md for actual evidence and unverified boundaries. No automatic public comments, QQ messages, work tasks or model requests are authorized by installation.
