# 本地长期记忆、人格自成长与完整人生存档（R30）

正式代码版本 1.9.0，已经本机验收，尚未发布安装包。普通角色保持可编辑；开启成长、重置和恢复都由用户明确操作。已验收的 30/60fps 媒体继续复用。

## 使用

打开 Galgame 的“管理角色”，管理窗口新增三个页签：

- **长期记忆**：按当前身份及允许知情范围查看核心、每日总结、Guide、话题和原始出处。正文只读；记错时通过正常对话纠正。失败的日终任务可重试，连接容量来源和保守估算会显示。
- **人格自成长**：主动选择“初始设定起步”或“白板起步”。普通角色不会自动转换。成长后人设、姓名和示例只读，模型连接、形象资源和健谈程度仍可设置。重新填写人设须经过完整人生重置。
- **人生存档**：保存当前人生、只读预览、整理名称备注、导出/导入 ZIP、重置及恢复。重置/恢复需要输入角色名确认；它们影响该角色全部身份的成套状态，身份关系不会相加。

## 实际行为

原文持续保存，只有实际呈现的回复才进入共同经历和奖励结算。群聊仍是首位自动、后续点击继续。生成未呈现内容不会成为共同记忆；恢复这种记录时标为中断，不自动补发。

保存设备 IANA 时区，以 00:00 分日。内部每分钟检查结束日期；关闭软件后下次启动补日。按角色、人生、知情范围、逻辑日幂等提交 Summary、核心变更、Guide 和成长候选。没有新经历不生成假日记；预设问候不触发整理。日期不明的真实旧记录保留原文并标明未知，不假定发生于 1970 年或迁移当天。

日常请求读取当前卡片、对应身份关系、允许的核心/Guide、当天原文和有关往事。普通记忆不因时间自动删除。更正保留原文与版本；“以后别再提”限制主动提及，主动询问仍受原来的权限约束。

容量使用连接显式设置或模型目录声明；未知时使用标明来源的保守 8192 上限，按 UTF-8 字节上界估算并预留回复。容量不足时用同一角色的聊天连接做分段工作摘要，原文保留；失败不静默截掉开头。当前使用应用侧文本压缩，未启用服务端不透明 compaction。长历史/整理会实际使用所选模型连接，不是免费本地推理。

人格按角色及人生共享，私人经历和关系按 Persona/群知情范围隔离。日终只提交带原始证据、版本、反证和安全抽象的小变化，允许无变化。观察标尺不是必定到期成长的规则，也不保证模型语义永远自然；成长轨迹不显示其他身份的秘密或内部推理。

## 存档与恢复

文字和图片分别存入 ZIP，附版本、逐文件 SHA-256、长度及资源依赖；重复图片按内容去重。人物自带动画按明确版本依赖复用，不复制进每个人生。自定义图片和必要 CG 实际携带。ZIP 的路径、重复条目、CRC、哈希、展开长度及图片解码都检查；单包安全上限 512 MiB、单份文本 64 MiB、单张图片 32 MiB。不存在存档数量、恢复次数或自动过期限制。

重置先保存并验证当前人生，再建立新人生。恢复也先保存当前人生，然后验证目标，使用持久化事务同步角色卡、原文/记忆、各身份关系、等级和内容进度；失败保留/恢复原状态。操作代号拦截旧任务，旧人生退出当前检索。共享群记录不随一人重置而删除，其他角色及实际用量/点击额度不回退，也不重放外部操作。导入仅加入独立条目，不自动激活；外观、连接和账号配置独立保留。

权威数据继续使用 `local/data-v003` 下现有伴侣及游戏快照存储，没有改数据库架构。新增人生 ZIP 存在 `galgame/life-archives`。不要仅备份一个最新摘要；完整备份应包含快照、人生 ZIP 和相应资源。

## 日终预算修复的实际验证

日终按完整序列化请求、来源索引、JSON 转义与输出预留预算。模型使用短来源编号，本地保留全部原始事件 ID、修订、文本哈希及冻结覆盖；只有确实提供的关联来源才能支持具体结论。普通模式不传成长专用资料，核心历史版本不反复塞入请求。

未知容量按 8192 规划时，日终分段、合并和最终请求为推理与 JSON 正文共享预留最多 4096 输出 tokens，输入相应缩小；不自动改变用户 effort。2026-10-20 的 DeepSeek、Claude、GPT 三条真实任务均已成功提交，各有 15 条完整来源。原文、卡片、Persona 及连接配置校验保留。测试中的 500 条来源覆盖、错误哈希、伪造引用和旧人生任务保护通过。真实模型语义仍可通过正常聊天纠错。
