用户于 2026-10-21 批准当前本机版本，作为 1.9.0 提交。此阶段只准备和提交代码，尚未发布 1.9.0 Release、安装器或下载附件。公开下载继续指向真实存在的 1.8.0；`release.json` 分别记录正式源码、已发布版本与复用的资源基线。

## 本版主要变化

- **角色与身份**：角色卡编辑、新建、逐字段继承/清空；Persona 与会话、草稿、回复选项及关系进度绑定，支持独立/共用关系切换。
- **角色独立连接**：默认使用全局聊天连接，可为每位角色选择已有专属 API 或本机 Codex 连接；各配置保留自己的模型和 effort，私聊/群聊统一使用有效连接。
- **群聊**：自然、列表顺序、手动及轮换模式；健谈程度属于角色卡；绑定身份的 `@` 成员输入；首位生成后，后续发言点击继续。成员加入/缺席时间过滤、串行请求去重及停止保护保留。
- **独立群聊舞台**：群名、在场成员、背景、记录、CG 图鉴和模型配置使用群聊自己的界面；站姿分区镜头、高亮发言者、八表情、成员浏览及全员总览。群聊合影依据已呈现内容生成，并可在图鉴查看大图。
- **桌宠互动**：局部手套、点击表情/好感额度、五分钟睡眠及唤醒、左拖走动、右拖甩飞和松左键发射的弹弓手势；保留任务反馈、资源切换与恢复逻辑。
- **新动作**：已验收的 11 位角色各 24 项、合计 264 项动作；在原 18 项上增加入睡、睡眠、唤醒、起飞、飞行和落稳。保留 30/60fps、125% 默认大小与角色尺寸基准，不重画或重新编码已批准素材。
- **长期记忆与上下文**：原文持续保存，按零点逻辑日整理 Summary/Guide，容量不足时分段与合并。普通记忆不自动淡忘；未呈现内容不计共同经历；Persona、私聊与群聊知情范围继续隔离。
- **人格自成长**：明确启用后才从设定或白板起步，默认角色不自动转换；来源、经历、日期与版本约束缓慢变化，前后端编辑锁生效。人格按角色共享，身份关系分别保存。
- **完整人生存档**：保存、预览、ZIP 导出/导入、重置和恢复成套角色状态；切换前保存当前人生，旧任务不能写入新人生，不回滚他人或账号账本。

## 日终预算修复

最终请求按完整适配器结构、JSON 转义、安全余量和回复预留一起预算。来源短编号只用于请求；完整事件 ID、原文、修订、哈希与覆盖清单保留本地，返回后严格反解。具体结论不得用整批覆盖冒充证据。

此前 8,192 窗口的验证中，日终分段、合并与最终请求为推理和 JSON 共预留 4,096 输出 tokens，输入相应缩小。随后用户确认未知模型采用 **272,000 tokens 应用默认值**，普通聊天、群聊和日终整理统一使用，来源标为 `application-default`、`verified:false`。手动设置和有效模型目录声明优先，明确的小窗口不被放大。日终输出预留仍最多 8,192，不修改用户 effort 或切换模型；完整原文、来源及预算校验保留。

实际本机重试的 2026-10-20 整理：DeepSeek、Claude、GPT 三条全部提交成功，各有 15 条完整来源，覆盖哈希及原文修订逐项通过，原文与模型配置保留。成功的日期不会重复生成。
