# AI 酱 2.0.9

2.0.9 整合本地配音、Live 轮流交谈和云音色管理。30fps 与 60fps 功能相同，复用已批准的角色和动作资源。

## 语音与组件

- 扩展中心提供 Breeze、GPT-SoVITS 两种本地引擎及共享识别组件；按角色管理参考声线。私人录音和本机声线参考不随发布上传，需自行导入。
- Galgame 可进入 Live 轮流交谈，录音后也可先形成可编辑草稿。准备、取消和停止按真实组件及音频状态处理；取消准备后不会继续开麦。
- MiniMax 支持命名配置、系统/克隆/设计音色、搜索筛选和角色绑定。收费克隆初始不勾选角色，只提交明确选中并确认的项目。
- 语音页、通用设置、聊天状态、Live 阶段、组件准备/导入及费用界面统一整理；牌桌有独立语音音量。
- 宿主管理组件下载、导入、进度恢复与取消，只准备所选本地引擎和共享组件；云模式不加载另一套本地 TTS。下载描述绑定签名包和原资源摘要，保留路径、字节数、完整性与升级重绑检查。

## 播放、性能与保存

- 健康的同一引擎切角色复用已加载组件；完整校验凭据可持久复用，状态读取避免反复扫描模型。私聊/群聊切换保留真实运行状态核对，不自动重开 Live 麦克风。
- 配音和文字呈现以实际播放开始同步，失败或超时明确放行；B站已保存分享及牌桌桌聊使用共享语音链。牌桌等待结果在切桌、换手或离页后不再应用。朗读过滤引用块及裸链接，保留正文，云端故障保留具体原因。
- B站图片能力使用按厂商和精确型号维护的目录，能力与传输协议分别判断；已知支持的型号正常发图，未知型号如实显示未知，不先自动发送额外探针。
- 减少高频状态读取中的整档复制、等待呈现时的全界面重建，以及用量/组件热路径的重复查询。一次本机 Auto+Breeze 的 60 秒对照中，鼠标延迟中位数由 165ms 降至 0.59ms，主线程单核占用约由 92% 降至 10%；该结果仅代表这次现场测量。
- companion/global 两大存档按每小时和正常退出等边界保存，检查、导出和导入前配对 flush。设置、草稿、请求 journal、钱包与用量数据库保留各自即时保存机制。掉电或强杀仍可能丢失两大存档自上次成功保存后的普通改动。
