# AI Buddy 2.0.14（修复候选，尚未发布）

2.0.13 已撤回，请继续使用 2.0.12；已经升级的用户可在安装器中回退上一版。2.0.14 修复 Windows 插件运行时与统一联网入口的回归，不改变聊天、记忆、钱包、角色、声线或牌局存档格式。

- DSH 运行时的网络预加载使用正确的文件 URL，修复 B站陪伴、QQ连接、一起玩牌及相关后端无法启动的问题。
- 需要自行核对跳转的请求改走支持手动重定向的传输，并继续使用相同的代理设置。保留组件地址白名单、跳转限制、TLS 和摘要校验，覆盖语音、NapCat、旧安装引导及模型服务跳转。
- Node 网络传输补齐缓冲请求体的长度、默认请求头、连接和响应头期限及响应地址信息；持续返回数据的响应不设整体时长上限。语音文件下载明确要求原始编码。
- 联网分区采用 AI-Buddy 版本标识；被 Chromium 禁止的端口显示具体提示。

本体沿用既有媒体、动画档位及运行库。插件没有业务修改，不重发插件包。语音 1.0.3 的本体下限仍为 2.0.13，2.0.14 满足该条件。

验收分别记录生产回归、真实 Electron 传输和最终安装候选，不能以扩展服务就绪代替插件页面握手。真实账号、付费模型、MiniMax 云配音和企业代理不在本次自动验收范围。最终逐项结果以交回的修复报告为准；未经用户确认，不发布、不安装日常版、不设为 Latest。
