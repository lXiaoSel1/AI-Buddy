# AI 酱 2.0.14

2.0.14 修复 2.0.13 的三个问题：官方插件无法启动，语音插件 1.0.3 装好后无法启用，语音组件和 QQ 连接组件下载失败。2.0.13 已经撤回，它的其他改动都保留在这一版里，见 [2.0.13 更新说明](RELEASE-2.0.13.md)。聊天、记忆、钱包、角色、声线和牌局的存档格式没有变化。30fps 与 60fps 两版功能相同；现有媒体、运行库和大模型组件继续复用。

## 修复

- 插件无法启动：2.0.13 启动插件运行时的时候，把联网预加载模块的 Windows 路径直接传给了 Node，而 Node 在这里只接受文件 URL，B站陪伴、QQ连接、一起玩牌和使用同一运行时的其他扩展全部启动失败。现在传文件 URL。
- 语音插件无法启用：语音 1.0.3 是和 2.0.13 一起发布的，但 2.0.13 认可的语音版本里漏了 1.0.3，装好后点「启用」会提示「当前主程序尚无此扩展的激活入口」。2.0.14 补上了，并且改了认插件的办法：本体以后按语音插件的大版本号认，1.x 的语音插件都能用。以后出 1.0.4 这样的新版，不用先更新本体；本体升级后，已经装着的 1.x 语音插件也不用跟着更新。只有语音插件出 2.x 时才需要更新本体。
- 要跳转的下载失败：2.0.13 把应用内的远程请求交给 Chromium 发送，而 Chromium 不让程序自己检查跳转。语音组件、QQ 连接组件（NapCat）和没有维护协议的旧安装的引导更新，都要先核对跳转地址再下载，所以第一步就失败；模型服务地址发生跳转时，「服务地址跳转到了…请直接填它」的提示也出不来。这类请求现在由 Node 发送，仍按「通用设置 → 网络」的代理设置走，地址白名单、跳转限制、证书校验和 SHA-256 核对都没有放宽。
- Node 发出的请求恢复了几处 2.0.12 的行为：带请求体的请求带 `Content-Length`（2.0.13 改成了分块发送，有些本机模型服务不接受）；默认带 `User-Agent`、`Accept` 和 `Accept-Encoding`；连接 10 秒没建立、响应头 300 秒没到会报超时，持续返回数据的回复和下载不限总时长。语音文件下载要求服务器不压缩，文件大小才能和清单核对。
- 系统代理的 PAC 同时给出 HTTP 和 SOCKS 代理时（Clash Verge 的 PAC 模式默认就是这样），2.0.13 把整条结果当成不支持，组件和插件包都下载不了。现在跳过 SOCKS 这一项，用剩下的 HTTP 代理或直连；只有 SOCKS 可用时，提示到「通用设置 → 网络」改用 HTTP 代理，或者选「不使用」。
- 主程序发出的请求没有自己指定 `User-Agent` 时，统一用 `AI-Buddy/版本号`；2.0.13 的远程请求带的是浏览器标识。CG、额度、云配音这些仍由 Chromium 发送的请求，遇到它禁用的端口时会提示「此端口被网络安全策略限制，请改用其他端口。」

## 更早就有、这次一起修的

- 发现页装插件：「安装…」现在装当前本体能用的最新一版，不再固定装目录里最新的；一个能用的都没有时，提示先更新 AI 酱或者到「版本」里选旧版，「版本」里也会标出每一版需要的本体版本。全新安装第一次装语音，不用先去「来源与旧扩展」刷新目录。安装页上的版本号是实际要装的那一版。
- 心情评估：这次模型调用失败后，以前会每秒重试一次、一直不停（2.0.3 起就有）。现在失败后隔 30 秒、2 分钟、10 分钟再试，之后每 30 分钟一次；连续 5 次失败就停下，等你发下一条消息；接口返回限流时按它要求的时间等。后台的心情和选项请求也不再挡住切换聊天连接。
- QQ连接：第一次连接时，连接组件解压后偶尔被系统暂时占用，现在会自动重试；仍然失败时提示等几秒再点「重新扫码」，不用重新下载。
- 一起玩牌：牌局中途改了角色的模型连接，现在直接出现「用现在的连接继续」和「作废这一手」，不用先刷新状态。
- 运行组件：缺运行组件时，插件页直接给「准备运行组件」；准备时显示已下载的大小。
- 其他：扩展中心「已安装」的数量把语音插件算进去；英文界面补了两处翻译。

## 升级

- 2.0.12 和更早的版本：运行 2.0.14 安装器，选原来的安装位置；或者在通用设置里更新。
- 已经装了 2.0.13：同样直接升级，不用先回退。已安装的插件、语音组件和存档都保留。
- 插件没有新版本：B站陪伴 2.0.16、QQ连接 2.0.10、一起玩牌 1.1.5 和语音 1.0.3 不变。语音 1.0.3 要在 2.0.14 上才能启用。

## 验证范围

- 这一版起，发布前要在安装好的程序上实际启动插件运行时，把 B站陪伴、QQ连接、一起玩牌各安装、启用一遍，确认插件页面连上自己的后端；语音插件也要从扩展中心安装并启用成功。只看到「扩展服务已就绪」不算通过。本体升级后更新旧版插件也要这样检查一次。
- 联网的修复用真实的 Electron 联网分区和本机搭的测试服务检查过，包括真实的 302 跳转和经代理的 HTTPS 连接。真实平台账号、付费模型、MiniMax 云配音和真实的公司代理没有测；SOCKS 代理仍不支持。
